Com isso, trazemos mais agilidade na finalização das planilhas e também damos o tempo que você merece para seguir com outras atividades.

Uso:

Como usar?

Em cada sistema, existe uma zona de upload de arquivos, onde o sistema capta os arquivos que são entregues. Em seguida, basta você iniciar o processamento: o sistema automatiza o processo e te entrega o arquivo processado.

Como funciona?

Desde o recebimento dos arquivos, o sistema utiliza a orientação de diretórios para manipular as rotas de destino das pastas de cada processo.

PENDENTES→Processos a serem automatizados
PROCESSADOS→Processos já finalizados
ERROS→Processados com erros
